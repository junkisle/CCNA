# Networking Components
- **End Devices** - Either the source or destination of a message transmitted over the network

![[Pasted image 20260803074502.png]]
- **Intermediary Devices** - Connects the individual end devices to the network
	- Uses the destination end device address to send the packet

![[Pasted image 20260803074520.png]]
- **Network Media** - Provides the channel which the message travels from
	- UTP Cables
	- Fiber-optic cables
	- Wireless
- **NIC** - Physically connects the end devices to the network
- **Physical Port** - Outlet on a networking device where the media connects to and end device or a networking device
- **Interface** - Specialized ports on a networking device that connects to individual networks

## Access Methods

| Method                 | Description                                                                                                                                                                                                                 |
| ---------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Console**            | - Physical management port that provides out-of-band access to a Cisco device.<br>- Accessible even with no networking service configured.<br>- Requires a terminal emulation software and special console cable to connect |

# IOS Navigation

## Primary Command Modes
### User EXEC Mode / View-only mode
- Limited capabilities
- Useful for basic operations
- Identified by the **>** symbol

 ![[Pasted image 20260809214358.png]]
### Privileged EXEC Mode
- Allows access to all commands and features
- Higher configuration modes are accessible through Privileged EXEC Mode
- Identified by the # symbol

![[Pasted image 20260809214416.png]]

## Configuration Mode and Subconfiguration Mode

### Global Configuration Mode
Mode used to configure the device
- Accessed before other specific configuration modes
- Identified by a prompt that ends with:
```
(config)#
```

From global config mode, the user can enter different subconfiguration modes.
### Line Configuration Mode
Used to configure console, SSH, Telnet, or AUX access
```
Switch(config-line)#
```
### Interface Configuration Mode
Used to configure a switch port or router network interface
```
Switch(config-if)#
```
## Navigate Between IOS Modes
To move from user EXEC mode to privileged EXEC mode, **enable** command is used. **Disable** command to return to user EXEC mode.

**Configure terminal** - used from privileged exec mode to enter **global configuration mode**. Use the command **exit** to return to privileged EXEC mode.

To enter a subconfiguration mode, use **line** command followed by the management line. Use **exit** to exit to return to global config mode

# Basic Device Configuration

## Device Names
### Naming standard to identify network devices
- Start with a letter
- Contain no spaces
- End with a letter or digit
- Use only letters, digits, and dashes
- Less than 64 characters in length

### Naming convention
Easily identify a specific device
![[Pasted image 20260810115218.png]]
```
Switch# configure terminal
Switch(config)# hostname Sw-Floor-1
Sw-Floor-1(config)#
```

## Password Guidelines
- More than eight characters in length
- Combination of upper and lowercases, numbers, special characters
- Avoid using same password for all devices
- Avoid using common words

## Configure Passwords
### Secured user EXEC mode

^cd1ae2

When you initally connected to a device, you are in user EXEC mode.

To secure user EXEC mode access, enter console configuration mode using **line vty 0**. 0 is used to represent the first (and in most case the only) console interface.

#### **password** *password*
Command to add a password to **user EXEC mode**

```
Sw-Floor-1# configure terminal
Sw-Floor-1(config)# line console 0
Sw-Floor-1(config-line)# password cisco
Sw-Floor-1(config-line)# login
Sw-Floor-1(config-line)# end
Sw-Floor-1#
```

#### **enable secret** *password*
Command to secure **privileged EXEC mode**
```
Sw-Floor-1# configure terminal
Sw-Floor-1(config)# enable secret class
Sw-Floor-1(config)# exit
Sw-Floor-1#
```

#### Securing Virtual Terminal (VTY) lines
Virtual Terminal Lines enable remote access using Telnet or SSH
- Cisco switches support up to **16 VTY lines**
```
Sw-Floor-1# configure terminal
Sw-Floor-1(config)# line vty 0 15
Sw-Floor-1(config-line)# password cisco
Sw-Floor-1(config-line)# login
Sw-Floor-1(config-line)# end
Sw-Floor-1#
```

## Encrypt Passwords
The startup-config and running-config display most passwords in plaintext. ^2056f9

#### **service password-encryption**
To encrypt all plaintext passwords, use this global config command
```
Sw-Floor-1# configure terminal
Sw-Floor-1(config)# service password-encryption
Sw-Floor-1(config)#
```
